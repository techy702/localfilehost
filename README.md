# Local Media Host

A web-based media hosting application that allows you to arrange and control media elements similar to OBS.

## Features

- Drag and drop media files from Finder
- Position and resize media elements
- Layer management system
- Media control (play/pause, loop)
- Scene-based organization

## Usage

1. Open `index.html` in your browser
2. Drag media files from Finder onto the canvas
3. Click and drag to reposition elements
4. Use resize handles to adjust size
5. Use the control buttons to add media types

## Features

- Add video files from local filesystem
- Add image files from local filesystem
- Drag and drop support for media files
- Resize and reposition elements
- Layer management
